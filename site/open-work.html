How this stays connected

These questions and statuses come from one work register. Every item links to the relevant source research. The overview presentation reads the current published work and research data when it opens or returns to view; there is no separate slide copy to update.

Research contributors update the canonical register and push the change. The existing publication workflow validates it and publishes the updated source page and data automatically. A network failure or an unpublished edit is not treated as an up-to-date presentation.
